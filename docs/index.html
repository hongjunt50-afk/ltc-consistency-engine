规则不是自己编的

全部来自《长期护理保险服务管理文书（2026 年版）》与《国家长期护理保险服务项目目录（试行）》（医保发〔2025〕24 号）。 抽取脚本从官方 PDF 直接读，并在抽取时做四类自校验，任一失败就不产出文件：

  • 数量：36 项 = 生活照护 20 + 医疗护理 16
  • 序号连续：1..20 与 1..16 不许断号
  • 三处副本逐字一致：同样 36 项在「护理服务建议表」「护理服务计划表」「月度汇总表」各出现一次，三种排版三种解析路径，得到的名称必须完全相同
  • 分区求和：巡查记录表 8 个分区的声明分值必须相加为 100，且分区内各检查项累加等于该区声明总分

pip install openpyxl
